# Telegram 自动群聊：服务器版

用户已选择服务器部署，沿用现有项目的 Telethon 个人账号登录方式，独立于签到项目运行。

- 单个指定群，读取最近 2 小时内最多 20 条有效文字，排除自己、机器人、命令和服务消息。仅有上次成功回复后新增的有效消息才生成回复。
- DeepSeek 官方 API，模型可配置，默认 deepseek-flash。上下文作为不可信数据放入 user 消息，中文短句通过本地字数与重复检查后发送；不合格最多重新生成一次。
- UTC+8 每日 08:00 至 15:00，15 个半小时时段。每个时段允许最多 5 分钟启动延迟，错过不补发；相邻实际发送至少间隔 30 分钟。无新消息或失败可少于 15 次。
- SQLite 持久记录时段、消息游标、回复摘要及冷却时间。发送前落盘预约，发送结果不确定时停止自动发送，人工核查后用命令解除。共用数据目录的重复进程由操作系统文件锁阻止。
- Docker Compose 常驻、持久卷、不开放入站端口。运行时从环境读取密钥，支持独立登录生成服务器专用 Session 文件。提供配置检查、群列表、只生成不发送预览、状态查看和启动命令。
- 测试使用真实 SQLite 和可控时钟，仅 Telegram 与 HTTP 边界使用替身，不连接真实账号或群。

服务器连接信息尚未提供。先完成可下载部署包，拿到服务器访问方式后才能进行真实部署。
